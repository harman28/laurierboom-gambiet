# Laurierboom-Gambiet 2

Team site for Laurierboom-Gambiet 2 (SGA 3e Klasse A, season 2026-2027): calendar, venues,
squad, and a page per opponent with a guessed board order.

Plain HTML/CSS/JS, no build step. Match data, rosters and ratings live in `data.js`
(sourced from https://sga.netstand.nl/teams/view/762). Venue addresses come from sgaschaken.nl.
Board order for opponents is just a sort by rating.
